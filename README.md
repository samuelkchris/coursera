# 500 Google Maps Places Directory

A comprehensive collection of 500 beautifully designed place interfaces representing various categories found on Google Maps.

## 🌟 Features

- **500 Unique Place Pages** - Each with custom content, icons, and color schemes
- **15 Categories** - Balanced distribution across different place types
- **Modern Design** - Clean, intuitive interfaces with smooth animations
- **Responsive Layout** - Works perfectly on desktop, tablet, and mobile
- **Interactive Index** - Search and filter functionality for easy navigation
- **Consistent Theme** - Unified design language across all pages

## 🚀 Getting Started

1. Open `index.html` in your web browser
2. Browse through all 500 places using the search and filter features
3. Click on any place card to view its detailed page
4. Each place page includes:
   - Rich content and descriptions
   - Customer reviews with ratings
   - Opening hours
   - Contact information
   - Features and amenities
   - Beautiful animations

- Pure HTML5
- CSS3 (with CSS Grid and Flexbox)
- Vanilla JavaScript

## 📝 Regenerating Sites

To regenerate all 500 sites:

```bash
node generate-sites.js
```

This will create/update all HTML files in the `places/` directory and update `sites-data.json`.
